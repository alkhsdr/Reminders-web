# Reminders by Alkis (web)

Εφαρμογή υποχρεώσεων για κάθε κινητό, χωρίς εγκατάσταση και χωρίς λογαριασμό.

**Άνοιγμα:** https://alkhsdr.github.io/Reminders-web/

- iPhone (Safari): Κοινοποίηση → Προσθήκη στην οθόνη Αφετηρίας
- Android (Chrome): ⋮ → Προσθήκη στην αρχική οθόνη

Τα δεδομένα μένουν μόνο στο κινητό του κάθε χρήστη.
